## 작업 상세 (시간순)

### 1. 디자인 구현 (INNOWAVE.dc.html → React)
- claude.ai/design 프로젝트 `1b81a3d8-…`에서 디자인 임포트 (DesignSync)
- `src/views/innowave/` 에 11개 화면 구현: 랜딩 / 로그인 / 워크플로우 1~4단계 / 기획안 확인 / 진행 입력 / 발주처 현황 / 내 프로젝트 / 관리자
- 공유 상태 컨텍스트(`state.tsx`), 데모 데이터(`data.ts`), 가상클래스 CSS(`innowave.css`)
- 라우팅 `App.tsx`, Space Grotesk 600 웨이트 추가

### 2. Firestore 실데이터 연동 (병렬 에이전트 5개)
- 데이터 계층 `hooks.ts` 신설 — 화면은 훅/컨트롤러만 사용
- 시드 데이터: events 10건(진행현황 evt-2·7·9), rateCards 120, personnelPool 500, caseData 80, quoteParams 3
- 화면별: 프로젝트 목록(events), 1단계(이벤트 생성/수정), 2단계(programs 서브컬렉션), 3단계(matchScoreFor 적합도 매칭 + matches 저장), 4단계(Quote 모델 실계산 + quotes 저장), 대시보드/진행입력(progress 실시간 onSnapshot), 관리자(레이트카드 CRUD·인력풀·케이스·견적 파라미터)
- 인증 가드 `RequireAuth` — rules상 모든 읽기는 로그인 필수

### 3. 계정·인증
- `jhc0902@gmail.com` → admin 등록 (`scripts/set-admin-role.mjs` 신설, 재사용 가능)
- Firebase Auth 승인 도메인에 `localhost`, `127.0.0.1` 추가 (Identity Toolkit API) — 로컬 Google 로그인 팝업 활성화
- 로그인 화면 **Google 전용**으로 전환 (이메일/비밀번호 폼 제거)

### 4. 게스트 퍼널 (비로그인 사용)
- 1~3단계 로그인 없이 체험 가능 (`guestInfo` 로컬 상태, 3단계는 데모 인력)
- 4단계 견적 **금액 블러 + Google 로그인 게이트** (로그인 시 즉시 실데이터 견적)
- React Router v7 future 플래그, 파비콘(`public/favicon.svg`) 추가

### 5. 사용자 계층 — 관리자 승인제
- 신규 가입 `users.approvalStatus = 'pending'` → 관리자 승인 후 프로젝트 생성 가능 (견적 열람은 로그인만으로 허용)
- 관리자 **사용자 관리 탭** 신설: 대기 뱃지, 승인/거절/이용 제한, 역할 변경(일반/발주처/관리자), 발주처 조직 ID 지정
- firestore.rules 서버 강제: 자가 승인 차단, events 생성은 승인 계정만

### 6. 고객문의 + 프로젝트 상세 허브 (병렬 에이전트 2개)
- **고객문의**: 랜딩 `#contact` 폼(비로그인 접수 가능) → `inquiries` 컬렉션 → 관리자 고객문의 탭(신규 뱃지, 상태 pill, 메모)
- **프로젝트 허브** `/project`: 행사 헤더, 4단계 진행 타일, 최신 견적 요약, 진행현황 요약, 인라인 확인식 삭제. 내 프로젝트 카드 클릭 → 허브 진입

### 7. 내비게이션 재정비 (GNB)
- 디자인의 하단 데모 화면전환 바 → **DEV 전용 접힌 칩(🧭)** 으로 격리
- 슬림 전역 헤더(GNB) 신설: 로고 / 내 프로젝트 / 관리자(admin) / 아바타(로그아웃)·로그인
- 랜딩·기획안·발주처 현황은 자체 상단 바 유지 (GNB 미노출)

### 8. Vertex AI 문서 분석 Phase 1
- `functions/` 워크스페이스 신설 (Node 22, TS, firebase-functions v2)
- `parseUploadedDocument`: Storage `uploads/{uid}/{docId}/…` 트리거 → 포맷 정규화(PDF inline base64 ≤10MB / DOCX·PPTX officeparser / HWPX XML 파싱 / HWP 미지원 안내) → **Gemini 2.5 Flash** (us-central1, responseSchema) → 9개 필드 `{value, confidence, evidence}` → `docParses/{docId}`
- 1단계 화면: 실제 업로드 → 실시간 구독 → 폼 자동 채움 + 신뢰도 배지(0.7 미만 "검토 필요")
- 트러블슈팅: ① 첫 배포 403 → Eventarc/GCS 서비스 계정 권한 부여, ② Vertex 500 INTERNAL → `global`+GCS URI 조합을 inline base64 + `us-central1`로 교체, 5xx 재시도 추가

### 9. 상태관리 개편 — 깜빡임 해결 (zustand)
- 원인: `/`와 `/:screen` 별개 라우트 → 앱 리마운트, 화면마다 데이터 재요청 → 스피너 깜빡임
- `path="*"` **catch-all 단일 라우트** (리마운트 제거)
- `useIwStore`(공유 상태) + `useCacheStore`(**stale-while-revalidate** 데이터 캐시, key 기반) — 재방문 즉시 렌더 + 백그라운드 갱신
- 모든 뮤테이션에 `invalidateCache`/`invalidateEvent` 연결, `useProgress` 스냅샷 캐시

### 10. 견적 → 프로젝트 → 발주처 공유 + PDF
- 4단계 공유 버튼: 프로젝트 없으면 **guestInfo로 자동 생성** 후 견적 저장 → 공유 문서 이동
- 기획안 화면: 승인/보완 요청 **제거** (링크 공유 모델로 단순화), `?event=` 파라미터 지원
- **공유 링크 복사** (`/proposal?event={id}`) + **견적서 PDF 다운로드** (`pdf.ts`: jspdf+html2canvas 지연 로드, 한글은 캔버스 렌더로 안전)
- PDF 여백 개선: A4 좌우 12 / 상 14 / 하 16mm, 페이지별 슬라이스 + 페이지 번호·INNOWAVE 푸터

### 11. 모바일 반응형
- 그리드 17곳 `minmax(min(100%, N px),1fr)` — 좁은 화면 가로 스크롤 제거

- ≤640px `overflow-x: hidden` 안전망
