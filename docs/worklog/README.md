# INNOWAVE 작업 로그

일자별 작업 내역을 기록하는 폴더입니다. 하루 작업이 끝나면 `YYYY-MM-DD.md` 파일로 남깁니다.

## 작성 규칙

- 파일명: `YYYY-MM-DD.md` (하루 1파일)
- 구성: **요약 → 작업 상세 → 인프라/배포 변경 → 이슈·사고 → 남은 일** 순서
- 코드 위치는 `경로:파일` 형태로 남겨 나중에 추적 가능하게
- 배포·권한·외부 설정 변경(콘솔 작업 포함)은 빠짐없이 기록
