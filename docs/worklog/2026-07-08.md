# 2026-07-08 — 첫 프로덕션 배포·OG 이미지·랜딩 완성

## 요약

Firebase Hosting에 앱을 처음 배포해 https://innowave-platform.web.app 라이브를 열었고, 소셜 공유용 OG 이미지를 제작·연결했다. 랜딩 헤더의 죽은 내비(서비스 소개/워크플로우/운영 사례)를 실제 섹션으로 기능화해 원페이지 마케팅 랜딩을 완성했다.

---

## 작업 상세

### 1. 첫 프로덕션 배포 (Firebase Hosting)
- `npm run build` → `firebase deploy --only hosting` — **https://innowave-platform.web.app** 라이브 (HTTP 200 확인)
- 배포 범위는 Hosting만 (rules/functions는 기존 배포 최신 상태 유지)
- `.firebaserc`+디렉터리 고정 덕에 올바른 프로젝트로 배포됨

### 2. OG 이미지 제작 (`public/og-image.png`, 1200×630)
- AI 생성 대신 **브랜드 HTML → 헤드리스 Chrome 렌더** 방식 — 한글 타이포(Pretendard)·로고 그라디언트 픽셀 정확
- 구성: 딥네이비 배경 + INNOWAVE 로고 + "MICE·공공 행사 기획을 위한 AI 자동화 플랫폼" 배지 + 히어로 카피(견적까지 그라디언트 강조) + 130+/500+/80건 통계 + 시그니처 웨이브 라인
- `index.html` 메타 갱신: 존재하지 않던 `innowave.ai` URL을 실제 배포 주소로 교체 (`og:image`·`og:url`·`canonical`·구조화 데이터), `og:image:width/height`·`twitter:image` 추가
- 라이브 확인: `/og-image.png` HTTP 200 (219KB). 카카오톡 캐시는 디벨로퍼스 공유 디버거에서 초기화 가능

### 3. 랜딩 내비 기능화 (기획 → 구현 → 검증 → 배포)
- **원페이지 앵커 구조**로 기획: 별도 페이지 대신 섹션 + 스무스 스크롤
- `#about` **서비스 소개 (신설)**: 실구현 3대 가치 카드 — AI 과업지시서 분석 / 표준 레이트카드 견적 / 발주처 공유·실시간 진행 (그라디언트 아이콘) + 운영사((주)이노웨이브 파트너스) 소개 라인
- `#workflow`: 기존 HOW IT WORKS 4단계 섹션에 앵커 + 하단 "지금 무료로 시작하기" CTA ("로그인 없이 3단계까지 체험" 카피)
- `#cases` **운영 사례 (신설)**: caseData 80건 중 유형별 대표 6건 정적 발췌(`SHOWCASE_CASES`) — 유형 배지·★만족도·주관·규모·성과. rules상 비로그인 조회 불가 + 예산액 비공개 판단으로 정적 큐레이션 채택
- 히어로 "운영 사례 보기" 버튼 → `#cases` 연결, 푸터 이용약관/개인정보처리방침은 가짜 링크 대신 "(준비 중)" 텍스트로 정리
- **검증**: SSR 렌더에서 앵커 3종·내비 링크 3종·섹션 콘텐츠·죽은 링크 부재까지 10항목 PASS
- 배포 + 푸시 (`0da288e`)
